# Waktu Solat & Kiblat

**Open the app: https://nuhihsan.github.io/qiblat-solat/**

On iPhone, open the link in Safari, then tap Share > Add to Home Screen.

Personal web app for Malaysia: JAKIM prayer times by GPS zone, Qibla compass, Islamic events calendar, solat guide, surahs with recitation, and a jamak/qasar checker.

- Prayer times: JAKIM e-Solat via https://api.waktusolat.app
- Offline fallback: local calculation (Subuh 20°, Isyak 18°, Asar Syafie, +2 min ihtiyat)
- Islamic events calendar (subscribe on iPhone): webcal://nuhihsan.github.io/qiblat-solat/islamic-events.ics

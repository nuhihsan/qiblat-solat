# Waktu Solat & Kiblat

Personal web app showing JAKIM prayer times (by GPS zone) and Qiblat direction for Malaysia.

- Data: JAKIM e-Solat via https://api.waktusolat.app
- Offline fallback: local calculation (Subuh 20°, Isyak 18°, Asar Syafie, +2 min ihtiyat)
- Install: open the GitHub Pages link in Safari, Share > Add to Home Screen
